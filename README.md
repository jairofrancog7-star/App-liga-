# Liga Juventino

Aplicación web/PWA y APK de la Liga Municipal de Fútbol Juventino Rosas.

## V7 — identidad visual

La versión actual incorpora las imágenes oficiales proporcionadas para:

- Pantalla inicial de la aplicación.
- Pantalla de “Actualizando datos”.
- Encabezado superior con emblema de la liga y acceso de cuenta.
- Icono de la aplicación/PWA.
- Generación automática del APK Android mediante GitHub Actions.

La interfaz base y las funciones existentes se mantienen; los cambios V7 se cargan desde `src/v7-brand.css` y `src/v7-brand.js`.
